# Отчёт: ИИ для игры Connect Four на алгоритме Minimax

## 1. Описание игры
Connect Four (Четыре в ряд) — игра для двух участников на доске 7 колонок × 6 рядов. Игроки по очереди бросают фишку в колонку, она падает до первой свободной клетки. Побеждает тот, кто первым выстроит 4 своих фишки подряд по горизонтали, вертикали или диагонали. Если доска заполнена без победителя, объявляется ничья.

Реализован режим «человек против ИИ» в Unity (C#). Человек играет красными и ходит первым, ИИ играет жёлтыми.

## 2. Как работает Minimax
ИИ строит дерево возможных ходов на ограниченную глубину:

- На уровнях **хода ИИ** выбирается ход с **максимальной** оценкой.
- На уровнях **хода человека** предполагается, что он сыграет лучшим для себя образом, то есть выберет ход с **минимальной** оценкой (для ИИ).
- Если позиция терминальная (победа, поражение, ничья), возвращается её точная оценка.
- Если достигнута предельная глубина, возвращается эвристическая оценка `Evaluate`.

В итоге ИИ выбирает ход, у которого результат лучший **даже при самом сильном ответе соперника**. Ход, после которого человек выигрывает следующим ходом, получает оценку около −100000, поэтому ИИ его избегает. Среди равных ходов предпочитается ближайший к центру. При равной победе быстрая оценивается выше (к оценке прибавляется оставшаяся глубина).

Основные функции в коде: `GetMoves` (допустимые ходы), `Apply` (применение хода к копии доски), `Winner` (проверка терминального состояния), `Evaluate`, рекурсивная `Minimax(board, depth, isMaximizing)`, `BestMove` (перебор ходов на верхнем уровне).

## 3. Оценочная функция
Терминальные состояния: победа ИИ **+100000**, победа человека **−100000**, ничья **0**.

Для нетерминальной позиции оценка складывается из:

| Признак | Вклад |
|---|---|
| Фишка ИИ в центральной колонке | +3 за фишку (у человека −3) |
| Линия из 4 клеток: 3 фишки ИИ + 1 пустая | +100 |
| Линия из 4 клеток: 2 фишки ИИ + 2 пустые | +10 |
| Линия из 4 клеток: 3 фишки человека + 1 пустая | −120 |
| Линия из 4 клеток: 2 фишки человека + 2 пустые | −10 |

Штраф за угрозу противника (−120) больше награды за свою тройку (+100), чтобы ИИ приоритетно блокировал соперника.

## 4. Пример хода ИИ
Ситуация: игрок поставил фишку в колонку 3, ходит ИИ.

Оценки из консоли Unity (Debug.Log в `BestMove`):

| Колонка | Оценка |
|---|---|
| 0 | -17 |
| 1 | -23 |
| 2 | -30 |
| 3 | -10 |
| 4 | -20 |
| 5 | -23 |
| 6 | -23 |

ИИ выбрал колонку **<N>**, так как у неё максимальная оценка **<значение>**. <Пояснение: например, ход занимает центр, а при любом ответе человека оценка позиции остаётся лучше, чем у других ходов.>

## 5. Ограничение глубины поиска
Полное дерево игры Connect Four содержит порядка 10¹² и более позиций, перебрать его за разумное время нельзя. Поэтому поиск ограничен глубиной **4 хода** (параметр `Search Depth`, допустимо 3–5). Это около 7⁴ ≈ 2400 листовых позиций на ход, ИИ отвечает мгновенно.

Цена ограничения: ИИ не видит последствий дальше горизонта поиска, поэтому на месте неизвестного исхода используется эвристическая оценка. Увеличение глубины делает ИИ сильнее, но время растёт экспоненциально (примерно в 7 раз на каждый дополнительный ход). Ускорить можно альфа-бета отсечением.

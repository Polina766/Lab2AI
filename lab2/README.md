# Connect Four (Четыре в ряд) с ИИ на Minimax

Игра «человек против ИИ» на Unity. ИИ выбирает ход алгоритмом Minimax с ограничением глубины и эвристической оценкой позиции.

## Требования
- Unity **<ВАША ВЕРСИЯ, например 6000.0.x>** (Unity Hub → Installs → версия указана там)
- Пакет TextMeshPro (при первом запуске согласиться на *Import TMP Essentials*)

## Как запустить
1. Клонировать репозиторий:
   ```
   git clone <ССЫЛКА_НА_РЕПОЗИТОРИЙ>
   ```
2. Unity Hub → **Add → Add project from disk** → выбрать папку проекта.
3. Открыть проект, в окне Project открыть сцену `Assets/Scenes/<ИМЯ_СЦЕНЫ>.unity`.
4. Нажать **Play**.

## Правила
- Вы играете красными и ходите первым, ИИ играет жёлтыми.
- Нажмите кнопку над колонкой, фишка упадёт в первую свободную клетку.
- Побеждает тот, кто первым соберёт 4 фишки подряд по горизонтали, вертикали или диагонали.
- Если доска заполнена, а четвёрки нет, ничья.
- Кнопка **Restart** начинает новую партию.

## Настройка сложности
У объекта `GameController` в Inspector поле **Search Depth** (3–5). Чем больше значение, тем сильнее и медленнее ИИ.

## Структура
- `Assets/Scripts/ConnectFour.cs`: логика игры, оценка позиции, Minimax, интерфейс.
- `REPORT.md`: отчёт по лабораторной работе.
